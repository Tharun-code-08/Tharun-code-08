## What I build

I build full-stack products where the interface, workflow, and underlying system have to hold up in real use. I’m studying Computer Science at Sathyabama in Chennai and work mostly with TypeScript, React, Node.js, and PostgreSQL.

## Selected work

### [SoftdigitIMS](https://github.com/Tharun-code-08/Inventory-control)

A multi-tenant inventory and ERP platform for retail shops. It covers procurement, batches and expiry, sales, invoices, analytics, and background jobs while keeping each shop’s data isolated. [Visit the product](https://softdigitconsulting.com/).

**Stack:** NestJS · React · Expo · PostgreSQL · Prisma · Redis · BullMQ

### [Captik Clipper](https://github.com/Tharun-code-08/Clipper)

A workflow for turning a long video into captioned vertical clips. It transcribes code-mixed speech, identifies promising moments, and gives creators a trim-and-style workspace before export.

**Stack:** Node.js · React · Remotion · FFmpeg · Python

### [THARUN OS](https://github.com/Tharun-code-08/tharun-os-portfolio)

An interactive 3D portfolio built as an explorable island and desktop-style operating system, with a straightforward résumé path for recruiters.

**Stack:** Next.js · React Three Fiber · Rapier · Blender · Web Audio
